# Sistema construído sobre o frame

Este é o repositório do **frame** puro: ainda não há sistema aqui.

Num sistema derivado (repositório próprio com `upstream` = frame-app), substitua este texto pelo contexto do
sistema: o que ele faz, entidades e regras de negócio, decisões, e o que NÃO pode mudar. O `CLAUDE.md` da raiz
continua sendo o do frame e importa este arquivo.
